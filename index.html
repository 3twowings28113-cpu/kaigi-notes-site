Kaigi Notes — 会議の記録とAI相談

オンライン会議の字幕とチャットを記録し、AI による要約や相談ができるブラウザ拡張機能です。

できること

  • Google Meet・Zoom（ブラウザ版）・Microsoft Teams（ブラウザ版）の会議で、字幕とチャットを自動で記録
  • 会議の記録から議事録・要約・ToDo を作成（AI 機能は利用者自身の API キーで動作）
  • Google カレンダーとつないで、今日の予定から会議へ参加、記録への予定情報の付与、日程調整
  • Google ドライブへの同期（利用者自身のドライブに、拡張機能が作ったファイルだけを保存）
  • Google タスクへの ToDo 登録、Gmail からの議事録メール送信（いずれも利用者がオンにしたときだけ）

Google のデータの扱い

本サービスが Google の API から受け取った情報の利用と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。データは利用者の端末と、利用者自身の Google ドライブ／カレンダー／タスク／Gmail の中だけで使われ、開発者のサーバーへ送られることはありません。詳しくは プライバシーポリシー をご覧ください。

入手方法

  • Microsoft Edge アドオン

About (English)

Kaigi Notes is a browser extension that records the captions and chat of online meetings (Google Meet, Zoom web client, Microsoft Teams web) and offers AI summaries and assistance using the user's own API key. Optional Google integrations — Drive sync (drive.file only), Calendar, Tasks, and Gmail send — are used solely as described in the Privacy Policy, in line with the Google API Services User Data Policy, including the Limited Use requirements. No data is sent to the developer's servers; the developer has none. Contact: 3twowings28113@gmail.com
