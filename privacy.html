Kaigi Notes プライバシーポリシー

最終更新日：2026年10月28日

Kaigi Notes（以下「本サービス」）は、オンライン会議の字幕とチャットを記録し、AI による要約や相談を行うブラウザの拡張機能です（パソコンの Chrome・Microsoft Edge・Vivaldi などと、Android の Vivaldi で使えます）。本サービスが扱うデータと、その保存先・送信先を説明します。

1. 扱うデータ

・会議の字幕：Google Meet・Zoom（ブラウザ版）・Microsoft Teams（ブラウザ版）の画面に表示された字幕の文字、話者名、時刻。記録がまだ始まっていない間・始まらなかったときも、会議の画面に出た字幕を端末の中に仮に残します（記録が始まればその記録に入ります。始まらなかったものは「未保存の記録」として、利用者が保存するか消すまで端末の中に残し、自動では消しません。「自動で記録しない」設定のときは仮に残しません）

・会議のチャット：利用者の画面のチャット欄に表示された送り主の名前、本文（リンクを含む）、時刻（設定でオフにできます）

・共有画面の画像：会議の参加者が画面を共有している間だけ、共有された画面を画像にしたもの（自動では参加者のカメラ映像は保存しません。設定でオフにできます）。利用者が「画面を保存」を押したときは、その時点の共有画面を画像にします（共有が見つからないときは、画面にいちばん大きく映っている映像で、参加者のカメラ映像のこともあります）

・会議の情報：会議名、会議コード、開始・終了の時刻、利用者が付けたタグと会議の種類

・予備音声モード・音声の保険を使ったときの音声：会議の音声と、利用者のマイクの音声。「音声の保険」は、字幕が取れない時間を音声で補うもので、会議の記録をしている間、自動で動きます（初期値はオン。設定でオフにできます）。利用者がその会議のタブで本サービスのアイコンを押していればタブの音声を、押していなければ、会議の画面が再生している相手の音声と、会議の画面がすでに使っているマイクの音声（会議でミュートしている間は録りません）を、会議の画面の中で録ります。どちらも端末の中に置き、字幕が取れなかった区切りだけを文字起こしに送ります。「マイクだけで記録」は、利用者が押したときだけ、利用者のマイクの音声だけを録ります

・Google カレンダーをつないだとき：今日の予定（名前・時刻・場所・会議の URL・参加者の名前とメールアドレス・利用者の出欠）と、カレンダーの持ち主のメールアドレス。会議を記録したとき、同じ会議の URL の予定があれば、その予定の名前・時刻・参加予定の人の名前（名前の無い人はメールアドレス）を会議の記録に付けます

・日程調整（Google カレンダーをつないだとき）：日程調整の画面を開いたときに読む予定（名前・時刻・空き／予定ありの区別・出欠）。利用者が追加したほかの Google アカウントの予定も、そのアカウントのメールアドレスと一緒に読みます。利用者が「仮押さえ」を押したときの仮押さえの予定（名前・日時）、利用者が貼り付けた相手の候補の文、日程調整の条件（会議の長さ・時間帯など）

・会議中に利用者が書いた「自分のメモ」と、その清書（「自分のメモを AI が清書」をオンにしたとき）、追跡するキーワード（「キーワードの追跡」をオンにしたとき）

・ユーザー辞書の自動の項目：「参加者の名前を辞書に入れる」がオンのとき（初期値はオン）、カレンダーの参加予定の人・字幕の話者・チャットの送り主の名前を、ユーザー辞書に入れます（設定でオフにでき、自動で入れたものはまとめて消せます）

・投稿先：利用者が設定でつないだ Slack・Microsoft Teams・Google Chat の受け取り用の URL（Webhook）と、その名前・どの会議を投稿するか

・画面共有中に開いたページ（「画面共有中に開いたページを残す」をオンにしたとき。初期値はオフ。オンにするときブラウザの「タブ」の許可を求めます）：利用者が自分の画面を共有している間に、ブラウザで表に出したタブのページの名前・URL・時刻と、共有していた時間。会議のタブ・拡張機能の画面・http(s) でないページは残しません。共有していないときのタブは読みません

・取り込んだ議事録：利用者が「取り込む」で選んだファイル（Word・テキスト・Web ページ）や貼り付けた文から読み取った、会議名・日時・要約・ToDo・文字起こし・参加者の名前（読み取りはこの端末の中で行います）

・プロジェクトのドライブのフォルダ（利用者が作ったとき）：フォルダの ID と名前、置く中身の選択、フォルダを共有したメンバーのメールアドレスと権限（見るだけ／編集）、会議ごとに置いた文書の ID

・診断のための情報：記録できていないことに気づいたとき、会議の画面の作り（ボタンの名前・字幕の欄があるかなど。字幕やチャットの文字は伏せ字）を、端末の中に最新3件まで残します。また、会議の画面をいつ・どう判定し、記録を始めたかどうか（検出の記録。時刻・タブの番号・会議の番号・判定の結果だけで、字幕やチャットの文字は入りません）を、端末の中に最新800件まで残します。どちらも利用者が「保存する」を押したときだけファイルにし、外には送りません

・利用者が入力した内容：アジェンダ、自分の名前、立場メモ、会議の前のメモ（話すこと・聞くこと・言うこと）、ユーザー辞書（言葉の正しい書き方と聞き間違い）、AI への質問、「ここ大事」の印とメモ、ToDo、フォローメールの宛先と指示、カレンダーに入れる予定、プロジェクト（会議をまとめるもの）の名前と説明、送り先（宛先のメールアドレス・チャットの URL）

・AI の回答：要約、議事録、相談への回答、フォローメールの下書き、ToDo と予定（会議から取り出したもの）、会議の前のメモの確認、話し方のふりかえり、プロジェクトの状況のまとめ、自分のメモの清書、会議前の準備メモ、週報の文

・字幕から数えた話し方の目安（話した量・話す速さ・問いかけの数など）。画面に出すときに端末の中で数えます（「AI にコーチしてもらう」を使ったときは、AI の回答として残ります）

・設定と、利用者が登録した AI の API キー（Google Gemini・Anthropic Claude・OpenAI・OpenRouter のうち登録したもの）

・同期をオンにしたとき：同期に使う Google アカウントのメールアドレスと表示名（どのアカウントで同期しているかを画面に出すためだけに使います）。会議の記録には、どの端末で記録したかを見分けるための印（ランダムな文字列）と端末の種類（例：Vivaldi・Windows）を付けます

2. 保存場所

・上のデータは、利用者の端末の中（拡張機能の保存領域）に保存します。

・会議ごとのファイル（.md と .txt）は、利用者のパソコンの「ダウンロード」フォルダに保存します。

・同期をオンにしたとき：上のデータ（音声を除く。共有画面の画像を含む）と設定・API キー・ユーザー辞書・次の会議のメモを、利用者自身の Google ドライブのマイドライブに本サービスが作るフォルダ「Kaigi Notes」に保存し、同じ Google アカウントでログインした利用者の他の端末（他のブラウザ・スマートフォンの Vivaldi）と同じ内容にします。このフォルダは利用者がドライブの画面で見られます。中には API キーも入るため、他の人と共有しないでください。本サービスが読み書きできるのは、本サービスが作ったファイルだけで、利用者のドライブの他のファイルを見ることはできません（Google の権限 drive.file だけを使います）。

・設定（API キーを除く）は、同期をオンにしていなくても、ブラウザの同期機能がオンのとき、利用者の Google アカウントを通じて、同じブラウザの他のパソコンに同期されることがあります。

・予備音声モード・音声の保険の音声は、文字起こしが終わると削除し、同期もしません。音の無い区切りと、字幕が取れていた区切り（区切りは約1分ごと）の音声は、文字起こしに送らずに削除します。字幕が途切れた区切りは、その区切りの音声をまとめて送り、字幕と重なる部分の文字起こしは使いません。

・投稿先の URL は端末の中に保存し、同期をオンにしているときは、利用者自身の Google ドライブのフォルダ「Kaigi Notes」を通して利用者の他の端末にも入ります（URL を知っている人はそこに投稿できるため、他の人と共有しないでください）。

・Google カレンダーの今日の予定は端末の中だけに置き（15分ごとに読み直します）、同期しません。日程調整の画面で読んだ予定は、画面を開いている間だけ使います（保存しません）。追加したほかのアカウントのメールアドレスと、仮押さえの一覧（予定の ID・日時・名前）は端末の中だけに置きます。つなぐのをやめると消します。会議の記録に付けた予定の名前・時刻・参加予定の人は、会議の記録と一緒に保存・同期します。

・お知らせ（設定で許可したとき）：記録が始まっていないとき・字幕が読めないとき・字幕や議事録を保存できなかったとき・記録を自動で終えたとき、カレンダーの会議が始まる少し前に、パソコンのお知らせに会議名・予定名を出します。外には送りません。拡張機能の裏の部分が応答しないときは、会議の画面の端に、利用者にだけ見える小さな案内を出します。

・会議の画面に付ける印：本サービスが2つ入っているとき（ストア版と開発版など）に1つだけが記録するよう、会議の画面に、本サービスの版と時刻だけの印を付けます（会議のサイトから読めます。字幕・利用者の情報は入りません）。

・「送る・共有」で共有リンクを作ったとき（同期のログインが必要）：利用者が選んだ中身（議事録・決まったこと・ToDo など）を Google ドキュメントにして、利用者自身の Google ドライブに本サービスが作るフォルダ「Kaigi Notes 共有した議事録」に置きます。このフォルダは同期のフォルダとは別で、「ドライブの同期データを消す」を押しても消えません。

・共有画面の画像は AI に送りません。利用者が「保存」を押したときだけ「ダウンロード」フォルダに保存します（同期をオンにしているときは、上のとおり利用者のドライブにも置きます）。

・自動メールの宛先・Notion のトークンと置き場所・Google タスクの一覧の名前は、設定として端末の中に保存します（同期をオンにしているときは、利用者のドライブにも置きます）。

・画面共有中に開いたページと取り込んだ議事録は、会議の記録と一緒に端末の中に保存します（同期をオンにしているときは、利用者のドライブにも置きます）。取り込むときに選んだファイルそのものは保存しません。

・プロジェクトのドライブのフォルダを作ったとき（同期のログインが必要）：利用者自身の Google ドライブに、本サービスが作るフォルダ「Kaigi Notes - プロジェクト名」に、会議のあと（利用者がオンにしたとき）または利用者が押したときに、そのプロジェクトの会議の議事録を Google ドキュメントで置きます。中身は利用者が選んだもの（議事録・ToDo・予定・ここ大事・全文のうち選んだもの）です。利用者はこのフォルダを、ドライブの好きな場所（チームの共有フォルダなど）に動かせます。

3. 外部への送信

本サービスがデータを外部に送るのは、次の場合だけです。どれも利用者の端末から直接送り、開発者のサーバーは通りません。

・AI 機能を使うとき（AI のボタン、自由入力、会議終了後の自動要約、フォローメールの下書き、過去の会議への質問、予定の書き出し、「AI で確かめる」（会議の前のメモ）、「AI にコーチしてもらう」（ふりかえり）、「メモを清書」「AI で準備メモを作る」「AI で週報の文にする」「AI で読み取る」（日程調整）、予備音声モード・音声の保険の文字起こし）：字幕とチャットの文字、会議名・時刻・タグ、Google カレンダーをつないでいるときはその会議の予定の名前・時刻・参加予定の人の名前（会議中に「次回いつにする？」のように日程を聞いたときは、明日から2週間の利用者の空き時間と、その間の予定の名前・時刻も）、「ここ大事」の印とメモ、利用者が入力した内容（自分の名前・会議の前のメモ・自分のメモ・ユーザー辞書の言葉（自動で入れた参加者の名前を含む）・プロジェクトの名前と説明・日程調整で貼り付けた文を含む）、プロジェクトの状況のまとめ、話し方の目安の数字を、利用者が設定で選んだ AI に、利用者自身の API キーを使って送ります。送り先は、Google の Gemini API（generativelanguage.googleapis.com）、Anthropic の Claude API（api.anthropic.com）、OpenAI の API（api.openai.com）、OpenRouter（openrouter.ai。利用者が選んだモデルの提供元にも渡ります）のうち、利用者が選んだ1つです。音声（予備音声モード・「マイクだけで記録」の音声と、音声の保険では字幕が途切れた区切りの音声だけ）は、Google の Gemini API にだけ送ります。会議の前のメモの自動のチェック、会議中の次回の候補、キーワードの追跡、週のまとめ・会議の時間の集計、会議前のブリーフ（AI のボタンを押す前まで）は端末の中で行い、AI には送りません。          同じプロジェクト・同じ会議 URL・同じタグの会議（定例など）では、前回までの会議の要約と終わっていない ToDo も一緒に送ります（設定でオフにできます）。

・プロジェクトに「まとめて聞く」「最新の状況をまとめる」を使ったときは、そのプロジェクトの会議の要約・ToDo・発言の一部を送ります。

・「過去の会議に聞く」を使ったときは、利用者が選んだ範囲の会議の要約・ToDo・発言の一部を送ります。

・取り込んだ議事録も、会議の記録として同じように扱います（AI 機能を使ったとき、その要約・文字起こしを送ることがあります）。画面共有中に開いたページは送りません。

・共有画面の画像は送りません。

・AI 機能を使う前に、設定画面で送る内容を示し、利用者の確認（チェック）を得ます。チェックを外すと送りません。会議終了後の自動要約は、設定でオフにできます。

・AI に送ったデータは、利用者が選んだ AI の提供元（Google・Anthropic・OpenAI・OpenRouter と、OpenRouter で選んだモデルの提供元）の利用規約とプライバシーポリシーに従って扱われます。Gemini API の無料枠と OpenRouter の無料のモデルでは、送った内容がサービスの改善や学習に使われ、人が確認することがあります。

・同期をオンにしたとき：上の「保存場所」のとおり、利用者自身の Google ドライブ（www.googleapis.com）に保存・読み込みします。ログインは Google の画面（accounts.google.com）で行い、本サービスはパスワードを扱いません。Google からの戻りは、ブラウザの仕組み（chrome.identity）で拡張機能が直接受け取ります。

・Google カレンダーをつないだとき：利用者自身の Google カレンダー（www.googleapis.com）から、今日の予定と、日程調整の画面で選んだ期間の予定を読み込みます（Google の権限 calendar.events.readonly）。ログインは同期と同じく Google の画面で行います。利用者が「ほかのアカウントを追加」を押したときは、そのアカウントでも Google の画面でログインし、そのアカウントのカレンダーの予定を読みます（読むだけで、書き込みはしません）。

・日程調整で「仮押さえ」「カレンダーに入れる」を押したとき（初めて押したときに Google の権限 calendar.events を求めます）：利用者自身の Google カレンダーに、仮押さえの予定（「【仮】」の付いた、利用者だけに見える予定）や、決めた日時の予定を作ります。「Google Meet の URL を作る」を選んだときは、Google に Meet の会議を作らせ、その URL を案内の文に入れます。日程を決めたときは、同じ日程調整の残りの仮押さえの予定を消します。どの場合も参加者は入れず、Google からお知らせのメールは送りません（相手への連絡は、利用者が案内の文をコピーして送ります）。

・同期をオンにしているとき（「Google ドライブに議事録を保存」。初期値はオン、設定でオフにできます）：会議が終わったら、会議名・日時と利用者が選んだ中身（初期値は議事録・ToDo・全文）を Google ドキュメントにして、利用者自身の Google ドライブの「Kaigi Notes 議事録」フォルダに保存します（同期と同じ権限 drive.file・www.googleapis.com）。だれとも共有しません。要約を作り直したときは新しいものに入れ替え、前のものはドライブのゴミ箱に移します。

・「メールで送る（自動）」をオンにしたとき（初期値はオフ。オンにするときに Google の権限 gmail.send を求めます）：会議が終わって AI の議事録ができたら、利用者が設定で決めた宛先（CC を含む）に、利用者自身の Google アカウント（Gmail API・www.googleapis.com）から、会議名・日時と利用者が選んだ中身（議事録・決まったこと・ToDo・予定・★・全文）をメールで送ります。送るのは利用者が入れた宛先だけで、会議の相手には送りません。受信箱や過去のメールは読みません。プロジェクトごとに、送る・送らない・別の宛先を変えられます。履歴の「書き出す」から手でも送れます。

・Notion をつないだとき（初期値はオフ。利用者が Notion で作ったインテグレーションのトークンを貼り、api.notion.com への通信の許可（任意のホストの権限）を与えたとき）：会議が終わって AI の議事録ができたら（自動をオンにしたとき）、または履歴の「Notion にページを作る」を押したとき、利用者が選んだデータベース（かページ）の下に、会議名・日時と利用者が選んだ中身のページを作ります（api.notion.com）。読むのは、利用者がそのインテグレーションに接続したデータベース・ページの名前と欄の種類だけです。トークンは端末の中（と、同期をオンにしているとき利用者のドライブ）にだけ保存します。

・「ToDo」タブで ToDo を選んで「Google タスクへ」を押したとき（初めて押したときに Google の権限 tasks を求めます）：選んだ ToDo だけを、利用者自身の Google タスクの一覧（初期値は「Kaigi Notes」という一覧を作ります。設定で変えられます）に、やること・担当・期限（日付）・会議名を付けて入れます。Google タスクからこちらに読み込むことはしません。

・会議中や履歴の「予定を入れる」で「カレンダーに入れる」を押したとき（初めて押したときに Google の権限 calendar.events を求めます）：利用者が画面で確かめた予定（名前・日時・場所・内容）を、利用者自身の Google カレンダーに作ります。下書きは、利用者がボタンを押したときに、会議の文字起こしと利用者の頼みを利用者が選んだ AI に送って作ります（ほかの AI 機能と同じ）。利用者が参加者のメールアドレスを入れたときだけ、その人を予定の参加者にします（メールアドレスは Google カレンダーにだけ送ります。相手が Google カレンダーを使っていれば、相手のカレンダーにも予定が出ることがあります）。利用者が「招待のメールを送る」を選んだときだけ、Google から参加者に招待のメールが届きます（初期値は送らない）。「Google Meet の URL を付ける」を選んだときは、Google に Meet の会議を作らせます。

・「送る・共有」でメールやチャットを開いたとき、「メールで開く」を押したとき：利用者が選んだ中身（議事録・決まったこと・ToDo・予定・ここ大事・全文のうち選んだもの、またはフォローメールの下書き）と、件名・宛先を、利用者が選んだサービスの作成画面に渡します：Gmail（mail.google.com）、Outlook（outlook.office.com・outlook.live.com）、パソコンのメールアプリ（mailto）、Microsoft Teams（teams.microsoft.com）。作成画面を開くアドレスに含めて渡すため、ブラウザの閲覧履歴にも残ります。本文が長いときと Google Chat（chat.google.com）は、本文をクリップボードにコピーして画面を開くだけです。送信するかどうかは、利用者がそれぞれの画面で決めます。本サービスはメールやチャットを送る権限を使いません。

・「共有リンク」を使ったとき：議事録を利用者自身の Google ドライブ（www.googleapis.com）に Google ドキュメントとして作り、利用者が選んだ相手（宛先のメールアドレス）に閲覧の権限を付けるか、利用者が選んだときは「リンクを知っている人なら誰でも閲覧できる」にします。Google アカウントの無い相手には、Google の決まりにより、Google から共有のお知らせのメールが届きます。

・プロジェクトのフォルダを「メンバーと共有する」を押したとき：プロジェクトの送り先の宛先（メールアドレス）に、そのフォルダを利用者が選んだ権限（見るだけ・編集もできる）で共有します（www.googleapis.com）。Google からお知らせのメールは送りませんが、Google アカウントの無い相手には、Google の決まりにより、Google から共有のお知らせのメールが届きます。フォルダに置いた議事録は、共有した相手も見られます。

・「カレンダーに追加」を押したとき：予定の名前・日時・場所・内容と元の会議名を、利用者が設定で選んだカレンダーの予定作成画面（Google カレンダー：calendar.google.com、Outlook：outlook.office.com・outlook.live.com）に渡します（アドレスに含めて渡すため、ブラウザの閲覧履歴にも残ります）。保存するかどうかは、利用者がカレンダーの画面で決めます（この機能では、カレンダーに直接は書き込みません）。

・「Google ドキュメントに貼る」「Notion に貼る」を押したとき：議事録をクリップボードにコピーし、新しい文書（docs.new・notion.new）を開くだけです。本サービスが内容を送ることはなく、貼り付けるかどうかは利用者が決めます。

開発者はデータを受け取るサーバーやウェブサイトを持っておらず、利用者のデータを受け取りません。利用状況の計測、広告、データの販売や第三者への提供は行いません（利用者が「送る・共有」で自分で選んだ相手に送る・共有する場合を除きます）。

6. 削除

・会議の記録は「履歴」から会議ごとに削除できます（字幕・チャット・AI 相談・ToDo・予定・共有画面の画像も一緒に消えます）。同期をオンにしているときは、利用者のドライブと他の端末からも消えます。

・拡張機能を削除すると、拡張機能の中のデータは消えます（同期をオンにしていた場合、ドライブの同期データは残り、入れ直してログインすれば戻ります）。

・投稿先は、設定の「投稿先」→「つなぐのをやめる」で消せます。投稿したメッセージは、それぞれのサービスで消せます。

Kaigi Notes Privacy Policy

Last updated: October 28, 2026

Kaigi Notes ("the service") is a browser extension that records the captions and chat of online meetings and offers AI summaries and assistance. It works in Chrome, Microsoft Edge, Vivaldi and other Chromium browsers on computers, and in Vivaldi on Android.

Data the service handles

・Meeting captions shown on the user's screen in Google Meet, Zoom (web client) and Microsoft Teams (web): caption text, speaker names and timestamps. Captions shown before recording starts, or when recording fails to start, are also kept provisionally on the device (they are added to the recording once it starts; otherwise they stay on the device as an "unsaved record" until the user saves or deletes it, and are never deleted automatically; this is off when automatic recording is turned off)

・Meeting chat shown in the chat panel on the user's screen: sender names, messages (including links) and times (can be turned off)

・Images of a shared screen, only while a participant is sharing their screen (camera video is never saved automatically; can be turned off). When the user presses "Save screen", the shared screen at that moment is saved (if no shared screen is found, the largest video on the page, which may be a participant's camera)

・Meeting details: meeting title, meeting code, start and end times, tags and meeting type set by the user

・Audio, in the fallback audio mode and the "audio backup": the meeting's audio and the user's microphone. The audio backup fills in times when captions cannot be read and runs automatically while a meeting is being recorded (on by default; can be turned off in Settings). If the user has clicked the extension's icon on that meeting tab, it records the tab's audio; otherwise it records, inside the meeting page, the other participants' audio that the page is playing and the microphone the meeting page is already using (not while the user is muted in the meeting). Both stay on the device, and only parts without captions are sent for transcription. "Record with the microphone only" records only the user's microphone, and only when the user presses it

・When the user connects Google Calendar: today's events (title, times, location, meeting URL, attendees' names and email addresses, and the user's response) and the calendar owner's email address. When a meeting with the same meeting URL is recorded, the event's title, times and attendees' names (email address if no name) are attached to the meeting record

・Scheduling (when Google Calendar is connected): events read when the scheduling screen is open (title, times, busy/free and the user's response), including events of other Google accounts the user adds, together with those accounts' email addresses; tentative holds the user creates (title, date and time); the candidate text the user pastes; and the scheduling conditions (meeting length, hours, etc.)

・The user's own notes written during a meeting and their AI clean-up (when "AI cleans up my notes" is on), and the keywords to track (when "Keyword tracking" is on)

・Automatic dictionary entries: when "add participants' names to the dictionary" is on (on by default), names of calendar attendees, caption speakers and chat senders are added to the user dictionary (can be turned off; automatic entries can be removed at once)

・Post destinations: the incoming webhook URLs of Slack, Microsoft Teams or Google Chat that the user connects in Settings, with their names and which meetings to post

・Pages opened while screen sharing (only when "Keep pages opened while screen sharing" is on; off by default; turning it on requests the browser's "tabs" permission): while the user is sharing their own screen, the title, URL and time of the browser tab the user brings to the front, and the times the user was sharing. The meeting tab, extension pages and non-http(s) pages are not kept. Tabs are not read when the user is not sharing

・Imported minutes: the meeting title, date and time, summary, to-dos, transcript and participant names read from the files (Word, text, web page) or text the user imports (read on the device)

・Project Drive folders (when the user creates one): the folder ID and name, the chosen contents, the email addresses and access level (view or edit) of members the folder was shared with, and the IDs of the documents placed for each meeting

・Diagnostics: when the service notices it is not recording, it keeps the structure of the meeting page (button names, whether a caption area exists, etc.; caption and chat text are masked) on the device, up to the latest 3. It also keeps a detection log on the device (when and how the meeting page was judged and whether recording started: times, tab numbers, meeting codes and results only, with no caption or chat text), up to the latest 800 entries. Both are saved to a file only when the user presses "Save" and are never sent anywhere

・Text the user enters: agenda, the user's name, a profile note, pre-meeting notes (things to say or ask), a user dictionary (correct spellings and common caption mistakes), questions to the AI, "important" marks and notes, to-dos, follow-up email recipients and instructions, calendar events, and project names, descriptions and send settings (recipient email addresses and chat URLs)

・AI responses: summaries, minutes, answers, follow-up email drafts, to-dos and events taken from the meeting, checks of the pre-meeting notes, speaking reviews, project status summaries, cleaned-up notes, pre-meeting prep notes and weekly report text

・Speaking statistics counted from the captions (share of talk, pace, number of questions, etc.), computed on the device when shown (kept only as part of the AI answer when the user asks for an AI review)

・Settings and the API keys the user registers (any of Google Gemini, Anthropic Claude, OpenAI and OpenRouter)

・When sync is turned on: the email address and display name of the Google account used for sync (only to show which account is syncing). Each meeting record carries a random device identifier and the device type (e.g. "Vivaldi・Windows") to tell which device recorded it

Where it is stored

Data is stored on the user's device (in the extension's storage) and, as files, in the user's Downloads folder. When the user turns on sync, this data (except audio, but including shared-screen images) together with the settings, API key, user dictionary and next-meeting notes is stored in a folder named "Kaigi Notes" that the service creates in the user's own Google Drive (My Drive), and kept the same across the user's devices signed in with the same Google account. The user can see this folder in Drive; because it contains the API key, it should not be shared. The service can only access files it created itself and cannot see any other files in the user's Drive (it only uses the drive.file permission). Settings other than the API key may also sync through the browser's own sync when it is enabled. Recorded audio is deleted after transcription and is never synced; silent parts and parts where captions were captured (in parts of about one minute) are deleted without being transcribed; for parts where captions dropped out, that whole part is sent and the transcript lines overlapping captions are discarded. Post destination URLs are stored on the device and, with sync on, copied to the user's other devices through the user's own Drive (anyone with the URL can post there, so they should not be shared). Today's calendar events stay on the device only (refreshed every 15 minutes), are not synced, and are deleted when the user disconnects the calendar; events read for scheduling are used only while the scheduling screen is open and are not stored; the email addresses of added accounts and the list of tentative holds stay on the device only; the event details attached to a meeting record are stored and synced with that record. When the user allows notifications, the meeting or event title is shown in the computer's notifications when recording has not started, captions cannot be read, captions or minutes could not be saved, recording was ended automatically, or a calendar meeting is about to start; nothing is sent. If the extension's background part stops responding, a small notice visible only to the user is shown at the edge of the meeting page. So that only one copy records when the service is installed twice (for example a store build and a development build), the service puts a marker with only its version and a timestamp on the meeting page (the meeting site can read it; it contains no captions or user information). When the user creates a share link (requires signing in for sync), the minutes are created as a Google Doc in a separate folder named "Kaigi Notes 共有した議事録" in the user's own Drive; this folder is not removed by "Delete sync data in Drive". Shared-screen images are never sent to the AI. Pages opened while screen sharing and imported minutes are stored with the meeting record (and synced with it when sync is on); the imported files themselves are not stored. When the user creates a project Drive folder (requires signing in for sync), the service creates a folder named "Kaigi Notes - (project name)" in the user's own Drive and, after each meeting of that project (when turned on) or when the user asks, places the minutes there as a Google Doc with the contents the user chose (minutes, to-dos, events, marks or transcript). The user may move this folder anywhere in Drive (for example, into a team folder).

When data leaves the device

All of the following are sent directly from the user's device; nothing passes through the developer's servers.

・AI features (AI buttons, free-form questions, the automatic summary after a meeting, follow-up email drafts, questions about past meetings, picking up events, checking the pre-meeting notes, speaking reviews, cleaning up notes, pre-meeting prep notes, weekly report text, reading candidates in scheduling, and transcription in the fallback audio mode and the audio backup): caption and chat text, meeting title, times and tags, the calendar event's title, times and attendees' names (when Google Calendar is connected; when the user asks the AI during a meeting to find a time for the next meeting, also the user's free time over the next two weeks and the titles and times of events in that period), "important" marks and notes, text the user entered (including the user's name, pre-meeting notes, the user's own notes, dictionary words including automatically added participant names, project names and descriptions, and text pasted for scheduling), project status summaries and speaking statistics are sent, using the user's own API key, to the one AI provider the user chooses in Settings: Google's Gemini API (generativelanguage.googleapis.com), Anthropic's Claude API (api.anthropic.com), OpenAI's API (api.openai.com) or OpenRouter (openrouter.ai, which passes it to the provider of the model the user picks). Audio (audio-mode and microphone-only recordings, and for the audio backup only the parts in which captions dropped out) is sent only to Google's Gemini API. Next-meeting suggestions during a meeting, keyword tracking, weekly and meeting-time statistics, and pre-meeting briefs (until the user presses the AI button) are computed on the device and send nothing. For meetings in the same project or group, summaries and open to-dos of previous meetings are also sent (can be turned off). When asking a project or summarizing its status, summaries, to-dos and excerpts of that project's meetings are sent. For questions about past meetings, summaries, to-dos and excerpts of the meetings in the scope the user chose are sent. Imported minutes are treated like other meeting records (their summaries and transcripts may be sent when the user uses AI features). Shared-screen images and pages opened while screen sharing are never sent. The automatic ticking of pre-meeting notes happens on the device and sends nothing. Before any AI use, the service shows what will be sent and asks the user to confirm with a checkbox; unchecking it stops all sending. Data sent to an AI provider is handled under that provider's terms and privacy policy (Google, Anthropic, OpenAI, OpenRouter and, through OpenRouter, the provider of the chosen model). With the Gemini API's free tier and OpenRouter's free models, the data may be used to improve services or train models and may be reviewed by people.

・Sync (only when turned on): data is saved to and read from the user's own Google Drive (www.googleapis.com). Sign-in happens on Google's page (accounts.google.com); the service never handles passwords. Google's response is received directly by the extension through the browser (chrome.identity).

・Google Calendar (only when connected): today's events and the events in the period chosen on the scheduling screen are read from the user's own Google Calendar (www.googleapis.com; calendar.events.readonly). Sign-in is the same as for sync. When the user presses "Add another account", the user signs in to that account on Google's page and its calendar events are read (read-only).

・Scheduling — "Hold" and "Add to calendar" (the first time, the calendar.events permission is requested): tentative holds (private events marked "【仮】") and the decided event are created in the user's own calendar. If the user chooses "Create a Google Meet URL", Google creates a Meet meeting and its URL is put into the invitation text. When a time is decided, the remaining holds of that scheduling are deleted. Attendees are never added and Google sends no update emails; the user sends the copied invitation text themselves.

・When sync is on ("Save minutes to Google Drive"; on by default, can be turned off in Settings): after each meeting, the meeting title and date and the parts the user chose (by default minutes, to-dos and transcript) are saved as a Google Doc in a "Kaigi Notes 議事録" folder in the user's own Google Drive (same drive.file permission as sync, www.googleapis.com). It is not shared with anyone. When the summary is regenerated, the document is replaced and the old one is moved to the Drive trash.

・"Send by email (automatic)" (off by default; turning it on requests the gmail.send permission): after a meeting, once the AI minutes are ready, the meeting title and date and the parts the user chose (minutes, decisions, to-dos, events, marks, transcript) are emailed from the user's own Google account (Gmail API, www.googleapis.com) to the recipients (and CC) the user entered in Settings — never to meeting participants. The inbox and existing mail are not read. Per project, the user can turn this on or off or use different recipients. It can also be sent manually from History.

・Notion (off by default; when the user pastes the token of an integration they created in Notion and grants the optional host permission for api.notion.com): after a meeting, once the AI minutes are ready (when automatic sending is on), or when the user presses "Create a Notion page" in History, a page with the meeting title and date and the chosen parts is created under the database (or page) the user chose (api.notion.com). Only the names and property types of the databases and pages the user connected to that integration are read. The token is stored only on the device (and in the user's Drive when sync is on).

・"To Google Tasks" on selected to-dos in the ToDo tab (the first time, the tasks permission is requested): only the selected to-dos are added to a list in the user's own Google Tasks (a list named "Kaigi Notes" is created by default; changeable in Settings) with the task, assignee, due date and meeting title. Nothing is read from Google Tasks.

・"Add an event" during a meeting or from History — when the user presses "Add to calendar" (the first time, the calendar.events permission is requested): the event the user has checked on screen (title, date and time, place, details) is created in the user's own Google Calendar. The draft is made, when the user presses the button, by sending the meeting transcript and the user's request to the AI the user chose (as with the other AI features). Only when the user enters attendees' email addresses are those people added as attendees (the addresses are sent only to Google Calendar; if they use Google Calendar, the event may appear in their calendar). Google sends invitation emails to attendees only when the user chooses "Send invitations" (off by default). If the user chooses "Add a Google Meet URL", Google creates a Meet meeting.

・"Save minutes to Google Calendar" (off by default; turning it on requests the calendar.events permission): after a meeting, the minutes (date and time, names of speakers, AI summary and to-dos) are written to the user's own calendar. For an event the user organizes with no other attendees, they are appended to its description; for other events, the original event is left unchanged and a private "議事録：" event visible only to the user is created at the same time (only if the user chooses "write to the original event" and is the organizer are the minutes written to the original event, where attendees can see them). Meetings that were not on the calendar get a new private event in the user's calendar for the time of the meeting. Attendees are never added and Google sends no update emails.

・Post destinations (only when connected): after a meeting, once the AI minutes are ready (meetings without AI minutes are not posted automatically), the meeting title, date and time, and the summary's key points, decisions, open items and to-dos (or the whole minutes, if chosen) are sent to the incoming webhook URL the user connected (Slack: hooks.slack.com; Microsoft Teams: logic.azure.com, powerplatform.com, powerautomate.com, webhook.office.com; Google Chat: chat.googleapis.com). Each meeting is posted once (unless the user re-sends it from History) and can be limited to selected projects.

・"Send / share" and "Open in mail": the parts the user selects (minutes, decisions, to-dos, events, marks or transcript, or the follow-up draft) with the subject and recipients are passed in the URL to the compose screen of the service the user chooses: Gmail (mail.google.com), Outlook (outlook.office.com, outlook.live.com), the computer's mail app (mailto) or Microsoft Teams (teams.microsoft.com). For long text and for Google Chat (chat.google.com), the text is only copied to the clipboard and the screen is opened. The user decides whether to send; the service has no permission to send email or chat messages.

・"Share link": the minutes are created as a Google Doc in the user's own Google Drive (www.googleapis.com) and shared read-only with the people the user chooses, or, if the user chooses, with anyone who has the link. For recipients without a Google account, Google sends its own share notification, as Google requires.

・"Share with members" for a project folder: the folder is shared, with the access level the user chooses (view or edit), with the recipient email addresses in the project's send settings (www.googleapis.com). The service asks Google not to send emails, but for recipients without a Google account Google sends its own share notification, as Google requires. People the folder is shared with can see the minutes placed in it.

・"Add to calendar": the event's title, date and time, place, details and the meeting title are passed in the URL to the event creation screen of the calendar chosen in Settings (Google Calendar: calendar.google.com; Outlook: outlook.office.com, outlook.live.com); the user decides whether to save (this feature does not write to the calendar directly).

・"Paste into Google Docs / Notion" only copies the minutes to the clipboard and opens a new document; the service sends nothing.

The developer runs no servers or websites that receive data and never receives any user data. There are no analytics or ads, and no data is sold or shared with third parties (except when the user chooses to send or share something with people they pick, using "Send / share").

Google user data

Kaigi Notes' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The Google Drive permission is used only to store the user's own records and settings in the user's own Drive and keep them the same across the user's devices, and, when the user presses "Share link", to create a minutes document and share it read-only with the people the user chooses, and, when the user creates a project folder, to place minutes documents in that folder and, when the user asks, share the folder with the project's members, and to save the minutes as Google Docs in a "Kaigi Notes 議事録" folder in the user's own Drive (can be turned off in Settings). The Google Calendar permission is used only to show today's events so the user can open a meeting in one click and be reminded shortly before it starts, to attach the matching event's title, times and attendees to the recorded meeting (and, when the user uses AI features, to include them in the meeting information sent to the AI as described above, and to add attendees' names to the user dictionary), and, when the user turns it on, to write the minutes to the user's own calendar after the meeting; to show free time for scheduling and, when the user presses the buttons, to create holds and the decided event (with a Meet meeting) in the user's own calendar; to pass the user's free time to the AI when the user asks it during a meeting to find a time for the next meeting; and, when turned on, for pre-meeting briefs, next-meeting suggestions and missed-recording reminders. The Gmail permission (gmail.send) is used only, when the user turns it on, to email the minutes to the recipients the user chose (no permission to read mail is requested). The Google Tasks permission (tasks) is used only to add the to-dos the user selects to the user's own task list. This data is never used for advertising, read by humans, used to train AI models, or transferred to third parties (except documents and folders the user chooses to share with people they pick, using "Share link" or project folder sharing).

Use

Data is used only to record, display and save meetings, manage to-dos, events and pre-meeting notes, organize meetings into projects, review the user's speaking, show today's events, open meetings and remind the user before they start, help schedule meetings (free time, candidate text, holds and creating events), compute weekly and meeting-time statistics and track keywords, write minutes to the calendar and post them to the user's destinations (when turned on), notify the user when recording is not working, sync the user's devices, prepare the sending and sharing the user asks for, and provide the AI features the user requests.

Deletion

Meetings can be deleted one by one from History (captions, chat, AI conversations, to-dos, events and images are deleted with them); with sync on, they are also deleted from the user's Drive and other devices. Sync can be stopped at any time in Settings. "Delete sync data in Drive" deletes everything in the "Kaigi Notes" folder and stops sync on the user's other devices (an empty folder with a short read-me remains and can be deleted in Drive). If the user deletes only the folder in Drive, devices with sync on recreate it from their local records at the next sync. Access can also be revoked from the Google Account settings (Third-party apps & services). Removing the extension deletes the data stored in it (data synced to Drive remains and comes back after reinstalling and signing in). Google Calendar can be disconnected at any time in Settings → Calendar, which also deletes the loaded events; minutes, events and holds written to the calendar can be deleted in Google Calendar (holds also from "Cancel holds" in scheduling); added accounts can be removed with "Remove". API keys can be deleted by clearing the field in Settings → "Set up AI" and pressing the test button. Post destinations can be removed in Settings → Post destinations; posted messages can be deleted in each service. Files in the Downloads folder can be deleted by the user. Projects can be deleted from the Projects tab (their meetings are kept). Documents created by "Share link" can be deleted or unshared by the user in the "Kaigi Notes 共有した議事録" folder in Drive. Project folders and the minutes placed in them can be deleted or unshared by the user in Drive ("Unlink the folder" in the project does not delete them). When a meeting is removed from a project or moved to another project, the minutes placed for it in the previous project's folder are moved to the Drive trash. Pages opened while screen sharing are deleted with their meeting record; turning the feature off stops keeping them and removes the browser's "tabs" permission. Imported minutes can be deleted from History like any meeting. Saving minutes to Drive can be turned off at any time under Settings → "Save minutes to Google Drive"; saved documents can be deleted by the user in the "Kaigi Notes 議事録" folder in Drive (deleting a meeting from History does not delete them). Automatic email can be turned off at any time under Settings → "Send by email (automatic)", and "Stop using the permission" stops using the Gmail permission (it can also be revoked in the Google Account's third-party apps settings); sent mail is in the user's Gmail "Sent" folder and can be deleted there. Notion stops being connected when the token is removed in Settings or the integration is deleted in Notion; created pages can be deleted in Notion. Tasks added to Google Tasks can be deleted there.
